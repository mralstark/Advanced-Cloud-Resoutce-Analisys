# Cloud Resource Allocation: Game Theory Analytics

## Описание проекта
Данный репозиторий содержит автономное одностраничное веб-приложение (SPA) для решения задачи распределения вычислительных мощностей облачного кластера с применением аппарата теории игр (антагонистическая матричная игра с нулевой суммой). Модель анализирует стратегии провайдера (выбор аппаратного пула) против паттернов нагрузки клиентов.

## Математический аппарат
Платформа реализует следующие аналитические алгоритмы:
* **Принцип доминирования:** Алгебраическая редукция неэффективных стратегий $M \times N \to 2 \times 2$.
* **Минимаксный критерий (Критерий Вальда):** Поиск равновесия Нэша в чистых стратегиях (седловая точка).
* **Графоаналитический метод:** Геометрическое нахождение оптимальных вероятностей $p^*$ и $q^*$ через расчет огибающих поверхностей.
* **Симплекс-метод (Линейное программирование):** Решение через формулировку прямой и двойственной задачи $Z = x_1 + x_2 \to \min$.
* **Метод фиктивного разыгрывания (Браун-Робинсон):** Стохастическая аппроксимация цены игры $V$ и смешанных стратегий.

## Технологический стек
* **UI/UX:** HTML5, CSS3 (CSS Variables, Flexbox, Grid).
* **Логика:** Vanilla JavaScript (ES6+).
* **Визуализация:** Zero-dependency SVG Builder (динамическая генерация DOM-элементов без внешних библиотек типа Chart.js или D3.js).
